# sales-performance-analysis
This report contains a beginner-friendly sales analysis project done in excel and Power BI 

## Tools Used
- Microsoft Excel
- Power BI
- SQL
  
## Project Overview
This Projects analyzes the monthly sales performance of a Business
It explores it's various sales Channels, total profit, total cost, monthly trends using interactive dashboard.

- KPI analysis
